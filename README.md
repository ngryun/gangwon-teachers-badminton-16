# 제16회 강원특별자치도 교직원배드민턴대회 · 경기일정

대회 운영본부의 「경기 대진표 및 경기 시간」(한글 파일)을 옮겨, **지역별 · 교사별 · 종목별**로 경기 시간과 코트를 바로 찾아보는 한 페이지입니다. 휴대폰 화면에 맞춰 만들었고 GitHub Pages로 배포합니다.

- 삼척시다목적체육관 · 11월 21일(토) 예선 / 11월 22일(일) 본선
- 종목 31 · 소속 217 · 선수 766 · 경기 721 (예선 565 + 본선 156)

## 쓰는 법

- **검색창** — 이름·학교·종목을 입력하면 바로 찾습니다.
- **지역별** — 시·군 → 소속(학교·기관) 순으로 좁혀 봅니다.
- **교사별** — 이름 첫 글자로 찾습니다. 예선 경기와, 조 1·2위로 올라갈 때의 본선 경로를 함께 보여 줍니다.
- **종목별** — 종목 → 조(또는 본선)로 좁혀 봅니다. 지역·소속을 고른 상태에서 종목을 고르면 둘 다 적용됩니다.
- `☆ 저장`을 누르면 그 기기에 즐겨찾기로 남고, `링크 복사`로 지금 보는 화면을 그대로 공유할 수 있습니다.

## 파일

- `index.html` — 화면 전체(스크립트·스타일 포함). 외부 라이브러리 없음.
- `data.js` — 경기 자료. `build_data.py`가 만듭니다.
- `build_data.py` — 한글 파일(.hwpx)에서 경기를 읽어 `data.js`를 만듭니다. 표준 라이브러리만 씁니다.
- `regions.json` — 소속 → 시·군. 원자료에는 지역이 없어 따로 붙인 표입니다.

## 대진표가 바뀌면

```bash
python3 build_data.py 새_대진표.hwpx
```

`data.js`가 바뀌면 커밋해서 올리면 됩니다. 새 소속이 생겼다면 `regions.json`의 `regions`에 추가하세요.

## 지역 ‘확인 필요’

강원도 안에 같은 이름의 학교가 여러 시·군에 있거나(교동초·남산초·반곡초·신동초·원당초·조양초) 소재지를 확인하지 못한 곳(하늘빛유)은 `regions.json`의 `unknown`에 두었고, 화면에는 ‘확인 필요’로 나옵니다. 확인되면 `regions`로 옮기고 `build_data.py`를 다시 돌리세요.
