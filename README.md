# 제16회 강원특별자치도 교직원배드민턴대회 · 경기일정

대회 운영본부의 「경기 대진표 및 경기 시간」(한글 파일)을 옮겨, **지역별 · 교사별 · 종목별 · 코트별**로 경기 시간과 코트를 바로 찾아보는 한 페이지입니다. 휴대폰 화면에 맞춰 만들었고 GitHub Pages로 배포합니다.

- 삼척시다목적체육관 · 11월 21일(토) 예선 / 11월 22일(일) 본선
- 종목 31 · 소속 218 · 선수 766 · 경기 721 (예선 565 + 본선 156)

## 쓰는 법

- **검색창** — 이름·학교·종목을 입력하면 바로 찾습니다.
- **지역별** — 지역(교육지원청) → 소속(학교·기관) 순으로 좁혀 봅니다.
- **교사별** — 이름 첫 글자로 찾습니다. 예선 경기와, 조 1·2위로 올라갈 때의 본선 경로를 함께 보여 줍니다.
- **종목별** — 종목 → 조(또는 본선)로 좁혀 봅니다. 지역·소속을 고른 상태에서 종목을 고르면 둘 다 적용됩니다.
- **코트별** — 코트를 고르면 그 코트의 경기를 시간순으로 봅니다. 경기 카드의 코트 번호를 눌러도 됩니다.
- 고른 조건은 각 목록 맨 앞의 `전체`를 누르거나, 조건 표시의 `✕`·`↺ 초기화`로 풉니다.
- `☆ 저장`을 누르면 그 기기에 즐겨찾기로 남고, `링크 복사`로 지금 보는 화면을 그대로 공유할 수 있습니다.

## 파일

- `index.html` — 화면 전체(스크립트·스타일 포함). 외부 라이브러리 없음.
- `data.js` — 경기 자료. `build_data.py`가 만듭니다.
- `bi.png`, `favicon.png` — 상단 ‘모두가 빛나는 강원교육’ BI와 파비콘.
- `build_data.py` — 한글 파일(.hwpx)에서 경기를 읽어 `data.js`를 만듭니다. 표준 라이브러리만 씁니다.
- `regions.json` — 소속 → 지역. 원자료에는 지역이 없어 따로 붙인 표입니다.
- `results.js` — 예선 점수 · 조 순위 · 본선 대진. `fetch_results.py`가 만듭니다. 없어도 화면은 대진표만으로 동작합니다.
- `fetch_results.py` — 페이스콕 대진 페이지(종목별 31쪽)를 한 번씩 읽어 `results.js`를 만듭니다. 표준 라이브러리만 씁니다.

## 대진표가 바뀌면

```bash
python3 build_data.py 새_대진표.hwpx
```

`data.js`가 바뀌면 커밋해서 올리면 됩니다. 새 소속이 생겼다면 `regions.json`의 `regions`에 추가하세요.

## 결과를 다시 받아 오려면

```bash
python3 fetch_results.py
```

페이스콕에 올라온 그 시점의 점수·순위·본선 대진을 받아 `results.js`를 바꿉니다. 화면에는 받아 온 시각이 함께 표시됩니다. 필요할 때 사람이 한 번씩 돌리는 용도이며, 자동으로 되풀이해 돌리지 않습니다. 실시간 결과는 화면의 페이스콕 링크로 안내합니다.

## 지역은 이렇게 붙였습니다

대진표에는 지역이 없어, 학교 코드로 소속별 지역을 붙인 뒤 「참가현황(최종)」의 **지역 × 종목 팀 수**와 대조했습니다. 지역 단위는 참가현황과 같은 교육지원청 단위(속초양양은 하나, 도교육청 본청은 `도교육청`)입니다.

- 이름이 같은 학교가 여러 지역에 있는 곳은 팀 수가 비는 지역으로 역추적했습니다: 교동초→원주, 남산초→강릉, 반곡초→원주, 원당초→양구, 조양초→속초양양, 하늘빛유→태백.
- **신동초**는 삼척 신동초(3팀)와 춘천 신동초(2팀)가 함께 출전해, 화면에 `신동초(삼척)`·`신동초(춘천)`으로 나눠 표시합니다(`regions.json`의 `split`).
- 참가현황 388팀 중 5팀(남복 20-30대 B 철원 1, 남복 20-30대 E 정선 1, 여복 20-30대 E 원주 1·정선 1, 여복 50대이상 A 속초양양 1)은 대진표에 없습니다.
